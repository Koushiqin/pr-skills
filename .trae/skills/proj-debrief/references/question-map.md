# 面试问题分类 · 考察点标签 · 追问路线

用途：给【面试提问】定"考察点"时从这里取标签，保证措辞稳定；给"可能的追问"时参考追问路线。
本文件持续维护：遇到新的考察方向就在对应分类下补充。

> 技术栈覆盖说明：本文件按实际使用持续补充。
> 遇到不在现有分类里的技术方向（前端、Go、iOS、大数据、Android、运维等），
> 参照下方已有格式追加新分类行即可。无需等作者更新，本文件是活的。

## 标签使用规则

- 考察点 = 分类标签 + 一句"面试官为什么问这个"
- 标签尽量复用已有措辞，不要每次造新词
- 一个问题通常只挂 1–2 个标签，主标签在前

## Java 后端方向

| 分类标签 | 覆盖的考察点 | 常见追问路线 |
|---|---|---|
| Java 基础与集合 | 数据结构选型、源码理解 | 底层结构 → 扩容/并发安全 → 为什么这么设计 |
| 并发与多线程 | 线程安全、锁、线程池 | 场景 → 选型理由 → 参数怎么定的 → 出过什么问题 |
| JVM | 内存模型、GC、调优 | 现象 → 怎么定位 → 怎么解决 → 指标变化 |
| Spring 生态 | IoC/AOP、Boot 自动装配、事务 | 画流程 → 失效场景 → 源码级解释 |
| 数据库与缓存 | 索引、事务隔离、Redis 用法 | 为什么这么建索引 → 慢查询怎么查 → 缓存一致性 |
| 消息与中间件 | MQ 选型、可靠性 | 丢消息怎么办 → 顺序/幂等 → 积压处理 |
| 系统设计 | 高并发、高可用、拆分 | 量级假设 → 瓶颈在哪 → 怎么扩 |

## AI Agent 应用方向

| 分类标签 | 覆盖的考察点 | 常见追问路线 |
|---|---|---|
| RAG | 检索链路、切块、召回质量 | 为什么这样切 → 效果不好怎么查 → 评估指标 |

| Agent 架构 | ReAct/规划、多轮状态 | 状态存哪 →  loop 怎么停 → 成本与延迟 |
| 模型评估 | 评估集、指标、回归 | 评估集怎么来 → 指标怎么算 → 上线后怎么监控 |
